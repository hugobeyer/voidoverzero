API Reference

Everything you need to know to use Rawteous Impostors in your Unity projects. From basic setup to advanced configuration.

Getting Started

Ready to get started? Here's the basics of adding impostors to your game objects.

Basic Setup

// First, add the impostor component to your object RawteousImpostors impostor = gameObject.AddComponent<RawteousImpostors>(); // Set up some basic settings for good quality impostor.settings.resolution = 512; impostor.settings.azimuthSteps = 8; impostor.settings.elevationSteps = 4; // Generate the impostor billboard! impostor.Regenerate();

Runtime Control

// Choose when to regenerate (when you release the mouse is usually best) impostor.settings.regenerationMode = RegenerationMode.OnMouseUp; // Get the materials and mesh that were created Material billboardMaterial = impostor.GetBillboardMaterial(); Mesh billboardMesh = impostor.GetBillboardMesh();

RawteousImpostors

This is the main component you'll work with. Just attach it to any GameObject and it will turn that object into a lightweight billboard that looks great from any angle.

Properties

Property Type What it does
settings RawteousImpostorsSettings All your configuration options live here
savedDecimatorRatio float How much to simplify the mesh (0-1). Lower numbers = more simplified

Methods

Method Parameters What it does
GetEffectiveTextureResolution() Tells you what resolution the texture actually ended up being
GetBillboardMaterial() Gets the material that was created for the billboard
Regenerate() Creates the impostor from scratch

RawteousImpostorsSettings

All the knobs and dials for customizing how your impostors look and behave.

Key Properties

Group Setting Type What it does
Capture resolution int How detailed the texture should be (256-4096)
Capture azimuthSteps int How many angles around the object to capture (4-32)
Billboard impostorMode ImpostorMode Choose between basic or smooth blending between angles
Workflow regenerationMode RegenerationMode When to update the impostor when you change settings

RegenerationMode

When should the impostor update when you tweak the settings?

Option What it does Performance cost
OnMouseUp Updates when you let go of the slider (recommended for most cases) Low - Only when you finish adjusting
OnChange Updates instantly every time you change anything High - Can get slow with complex objects
RealTime Live preview that updates as you work Medium - Smooth but uses more resources

ImpostorMode

How should the impostor blend between different viewing angles?

Mode How it works Best for
TextureBased Simple switching between pre-captured angles Most common choice, fastest performance
SmoothBlending Gently blends between angles for smoother rotation Better looking, but uses a bit more GPU

Usage Examples

Here are some real-world examples of how you might use Rawteous Impostors in your games.

Runtime Impostor Generation

using UnityEngine; using RawteousImpostors.Runtime; public class ImpostorManager : MonoBehaviour { public void ConvertToImpostor(GameObject target) { // Give the object the impostor powers var impostor = target.AddComponent<RawteousImpostors>(); // Set up reasonable quality settings for performance impostor.settings.resolution = 256; impostor.settings.azimuthSteps = 6; impostor.settings.elevationSteps = 3; impostor.settings.impostorMode = ImpostorMode.TextureBased; // Make it happen! impostor.Regenerate(); } }

Batch Processing

public class BatchImpostorGenerator : MonoBehaviour { public GameObject[] targets; public RawteousImpostorsSettings templateSettings; public void GenerateAllImpostors() { foreach (var target in targets) { // Convert each object to an impostor using our saved settings var impostor = target.AddComponent<RawteousImpostors>(); impostor.settings = templateSettings; impostor.Regenerate(); } } }
