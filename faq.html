Rawteous

What is Rawteous?

Rawteous is an advanced impostor generation system for Unity. It allows you to create lightweight billboard representations from any 3D object with GPU acceleration and real-time preview, significantly improving performance in your Unity projects.

What Unity version does Rawteous support?

Rawteous supports modern Unity versions. Please check the Rawteous documentation for specific version requirements and compatibility information.

Is Rawteous GPU accelerated?

Yes! Rawteous uses GPU acceleration for impostor generation, providing fast processing times and real-time preview capabilities. This makes it ideal for optimizing large scenes with many objects.
