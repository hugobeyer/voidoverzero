Learn how to use Rawteous Impostors with practical, hands-on tutorials. From basic setup to advanced optimization techniques.

Getting Started

New to Rawteous? Follow this tutorial to create your first impostor in minutes.

Step 1: Install Rawteous

If you haven't already, import the Rawteous Impostors package into your Unity project:

  1. Open Unity Package Manager (Window → Package Manager)
  2. Click the "+" button and select "Add package from disk"
  3. Navigate to the Rawteous Impostors package folder
  4. Select the package.json file

Step 2: Prepare Your 3D Object

Select any GameObject in your scene that you want to convert to an impostor. This can be:

  • A character model
  • A prop or decoration
  • A building or structure
  • Any 3D object with a mesh renderer
💡 Tip: Objects with complex geometry work best. The impostor system will capture multiple angles automatically.

Step 3: Add the Rawteous Component

With your GameObject selected:

  1. Click "Add Component" in the Inspector
  2. Search for "Rawteous Impostors"
  3. Add the component to your GameObject

The component will appear in the Inspector with default settings.

Step 4: Configure Basic Settings

For your first impostor, start with these recommended settings:

  • Texture Resolution: 256 or 512 (good balance of quality and performance)
  • Azimuth Steps: 8 (captures 8 angles around the object)
  • Elevation Steps: 4 (captures 4 vertical angles)

Step 5: Generate Your Impostor

Click the "Regenerate" button in the Inspector. Rawteous will:

  1. Capture the object from multiple angles
  2. Create an impostor texture atlas
  3. Generate a billboard mesh
  4. Replace the original mesh with the impostor
💡 Tip: The first generation may take a few seconds. Subsequent regenerations are faster thanks to caching.

Step 6: Test Your Impostor

Move your camera around the object in Play mode. You should see:

  • The impostor switching between different captured angles
  • Smooth transitions as you rotate around the object
  • Significantly better performance compared to the original mesh

Performance Optimization

Learn how to optimize your impostors for the best performance without sacrificing visual quality.

Understanding Resolution vs. Performance

The texture resolution directly affects both quality and memory usage:

  • Low (64-128): Best for small objects, background elements, or mobile games
  • Medium (256-512): Good balance for most use cases
  • High (1024+): Best for main characters or important objects

Reducing Capture Steps

Fewer capture steps mean faster generation and smaller textures:

  • Azimuth Steps: 4-6 steps work well for most objects
  • Elevation Steps: 2-3 steps are usually sufficient
⚠️ Warning: Too few steps may cause visible "popping" when the camera rotates. Test in your game to find the sweet spot.

Using Texture-Based Mode

For maximum performance, use Texture-Based mode instead of Smooth Blending:

This mode switches between angles instantly without blending, which is faster but may be slightly less smooth.

Batch Processing Multiple Objects

If you need to convert many objects, you can add the Rawteous component to multiple objects at once:

  1. Select multiple GameObjects in the Hierarchy
  2. Add the Rawteous Impostors component (it will be added to all selected objects)
  3. Configure settings on one object, then copy the component settings to others
  4. Regenerate each impostor individually or use a batch script

Advanced Techniques

Take your impostor skills to the next level with these advanced techniques.

Custom Capture Settings

Fine-tune how Rawteous captures your object:

  • Capture Distance: Adjust how far the capture camera is from the object
  • Field of View: Control the camera's field of view for better framing
  • Background Color: Set a transparent or colored background

Runtime Impostor Generation

You can generate impostors at runtime for dynamic content. This is useful for procedurally generated objects or objects created during gameplay.

To set this up:

  1. Create a script that adds the Rawteous component to objects at runtime
  2. Configure the settings programmatically
  3. Call Regenerate() to create the impostor
  4. Optionally disable the original mesh renderer

LOD System Integration

Use impostors as part of a Level of Detail (LOD) system:

  1. Keep the original mesh for close-up views
  2. Switch to impostor when the object is far away
  3. Use distance-based switching logic

Optimizing for Mobile

Special considerations for mobile platforms:

  • Use lower resolutions (128-256)
  • Reduce capture steps (4-6 azimuth, 2 elevation)
  • Use Texture-Based mode for better performance
  • Test on actual devices, not just the editor

Troubleshooting

Common issues and how to fix them.

Impostor Looks Blurry

Problem: The impostor texture appears low-quality or blurry.

Solutions:

  • Increase the texture resolution setting
  • Check that your object isn't too large relative to the capture distance
  • Ensure the original mesh has good detail

Visible Popping Between Angles

Problem: You can see the impostor switching between captured angles.

Solutions:

  • Increase azimuth and elevation steps
  • Switch to Smooth Blending mode
  • Adjust the capture distance

Impostor Not Generating

Problem: Clicking "Regenerate" doesn't create an impostor.

Solutions:

  • Ensure the GameObject has a MeshRenderer
  • Check that the object is visible in the Scene view
  • Verify the object has valid geometry
  • Check the Unity Console for error messages

Performance Issues

Problem: Game runs slower after adding impostors.

Solutions:

  • Reduce texture resolution
  • Decrease capture steps
  • Use Texture-Based mode
  • Limit the number of impostors visible at once
